Visual reference: **Weatherman Dashboard**, designed by Madelena Mak (2022),
https://github.com/Madelena/esphome-weatherman-dashboard and
https://community.home-assistant.io/t/435428.

`../weatherman.py` is an independently written renderer. No
ESPHome YAML, Gotham Rounded font binaries, or Weatherman bitmap assets
are redistributed here. The renderer does not install ESPHome or alter the
frame firmware. Its original Python drawing code follows this project's
CC-BY-NC-SA-4.0 license; third-party fonts retain their separate licenses.

  from https://github.com/google/fonts/tree/main/ofl/nunito.
  Copyright and license are preserved in `Nunito-OFL.txt` (SIL OFL 1.1).
- **Material Design Icons 7.4.47** by Pictogrammers:
  https://github.com/Templarian/MaterialDesign-Webfont/tree/v7.4.47.
  Font downloaded unmodified; see `MDI-LICENSE.txt` and `Apache-2.0.txt`.

These resources are included in the add-on image and reused by local previews.
